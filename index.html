🏗 - Layout Editor

🧭 Controls & Shortcuts

🖱️ Mouse

  • Left Click — Select a room or vertex
  • Drag vertex — Move vertex
  • Drag near edge — Move edge
  • Shift + Drag edge — Slide edge perpendicular only
  • Right / Middle drag — Pan the canvas
  • Scroll — Zoom at cursor

⌨️ Keyboard

  • G — Toggle grid snap
  • R — Rename selected room
  • S — Save edited layout
  • U / Ctrl+Z — Undo last change
  • C — ✂️ Add Vertex mode (click edge to insert)
  • Esc — Cancel Add Vertex or current action
  • A — Align selected edge to another (coming soon)

🧰 Tools

  • Grid — Toggle drawing grid visibility
  • Align — Snap edges to adjacent rooms
  • Snap Step — Adjust grid snapping precision
  • Units — Choose display units (m, cm, mm, ft)
  • ✂️ Add Vertex — Insert new vertex along edge
  • 💾 Save — Export modified layout JSON
  • 📂 Load — Import JSON layout
  • 🔄 Reset — Fit all rooms in view

💡 Tips

  • Hover edges — Highlight nearest edge in yellow
  • Selected room label turns red
  • Use Undo freely — all edits are reversible
  • Zoom in for precise vertex editing
